## 6. Documentation Standards

Apply consistently across repositories.

### Project README Checklist

- [ ] Research question / objective
- [ ] Brief project overview
- [ ] Data sources
- [ ] Methodology
- [ ] Results and findings
- [ ] Limitations
- [ ] Software and dependencies
- [ ] File organization
- [ ] Reproduction instructions, when applicable
- [ ] Links to reports or publications

### General Conventions

- Use descriptive folder and file names.
- Maintain consistent naming and capitalization.
- Separate raw data, transformed data, code, and outputs.
- Avoid uploading unnecessary intermediate files.
- Identify simulated data explicitly.
- Do not claim results unsupported by published materials.
- Distinguish complete projects from exploratory work.
- Preserve original research versions where relevant.
